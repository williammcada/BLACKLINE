# BLACKLINE: Last Exit

A MathQuest cartridge with an original 16-bit-inspired racing escape mini-game. The standalone HTML is its development/playtest harness, not a separate product. Brake through industrial switchbacks, launch across broken highways and outrun lethal pursuers.

**Current status:** Design accepted; first mini-game implementation authorized. There is no playable build or verified release yet.

**Immediate target:** v0.1.0-alpha.1 — a short standalone driving-and-jump prototype.

**Canonical repository:** https://github.com/williammcada/BLACKLINE (initial source commit `177690799fabab5bd12a057eb9ce4a72fcc42d37`).

## Build sequence

1. Preserve the cartridge design documents in this canonical repository.
2. Build the short driving proof: road, hills, bends, braking, boost and one jump.
3. Preserve an implementation checkpoint and perform the specified checks.
4. Deliver the playable alpha for handling feedback.
5. Add pursuit, the complete course and final presentation in separate milestones.
6. Integrate the MathQuest cartridge and Math Arcade adapters later.

No install, build or play command is supplied yet because no implementation exists.

The first artifact will be a self-contained HTML file generated from maintainable source. Desktop keyboard and landscape iPhone/iPad touch are targets, not verified support claims. Hosted iOS delivery is planned; a downloaded iOS HTML file-opening workflow is not promised.
